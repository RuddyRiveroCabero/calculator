# JavaScript Calculator

A web calculator application built with JavaScript, HTML, and CSS.

## About The Project
This project was built to practice core JavaScript programming concepts, specifically state management, event handling, dynamic UI updates, and implementing mathematical operational logic directly in the DOM.

## Key Learnings
* **DOM Manipulation:** Dynamically updating values and displaying results in real-time.
* **Event Handling:** Capturing user inputs from both click events.
* **Logic & Edge Cases:** Managing calculator states, tracking operand status, and handling error states (such as division by zero).

## Features
* Standard arithmetic operations (Addition, Subtraction, Multiplication, Division).
* 18-digit input limit and decimal support.
* Clear button to reset memory and screen state.
* Clean layout designed for desktop with CSS Grid.

## Built With
* JavaScript
* HTML
* CSS (CSS Grid)
