# JavaScript Calculator

A clean, responsive web calculator application built with vanilla JavaScript, HTML5, and CSS3.

## About The Project
This project was built to practice core JavaScript programming concepts, specifically state management, event handling, dynamic UI updates, and implementing mathematical operational logic directly in the DOM.

## Key Learnings
* **DOM Manipulation:** Dynamically updating values and displaying results in real-time.
* **Event Handling:** Capturing user inputs from both click events and key presses.
* **Logic & Edge Cases:** Handling mathematical operations, preventing floating-point precision issues, and managing error states (such as division by zero).

## Features
* Standard arithmetic operations (Addition, Subtraction, Multiplication, Division).
* Clear button (`AC`) to reset memory and screen state.
* Clean, responsive layout designed for both desktop and mobile viewports.

## Built With
* JavaScript (ES6+)
* HTML
* CSS (Flexbox / CSS Grid)
